拓扑排序

拓扑序 = DAG 的线性化：把「u 在 v 前」的偏序展平成一条链。
所以只有 DAG 才有拓扑序。队列弹出数 < n ⇒ 有环 —— 判环万能判据。

P1347 排序

P1347 [ECNA 2001] 排序 - 洛谷

这道题就是边排序边判断，其他都可以套模板。每读入一条关系就重跑一遍拓扑，返回三种状态：

  • -1：弹出点数 cnt < n，说明有环，矛盾；
  • 1：cnt == n 且队列任何时刻都只有一个元素（sure 没被置 false），说明拓扑序唯一，可以确定；
  • 0：能排完但不唯一，信息不足，继续加关系。

P1137 旅行计划

P1137 旅行计划 - 洛谷

这道题参杂了一点点 dp，因为最大城市数取决于之前的情况，走过的岔路口肯定要判断一下怎么走最优。

把入度为 0 的点（起点）dp 初始化成 1，然后在 Kahn 的松弛过程中转移：dp[v] = max(dp[v], dp[u] + 1)。因为队列弹出的顺序天然是拓扑序，转移到 v 时它的所有前驱都已经算完了

P4017 最大食物链计数

P4017 最大食物链计数 - 洛谷

也就是求一共有几条生物链，最大的意思就是从生产者到最顶端的消费者，路径 dp 取模。

和上一题是同一个骨架，区别在于转移从取 max 变成累加计数：

  • 起点（入度 0，即生产者）dp[i] = 1；
  • 转移 dp[v] = (dp[v] + dp[u]) % mod；
  • 答案不再是所有点求和，而是只累加出度为 0 的点（g[i].empty()，即食物链顶端）。
