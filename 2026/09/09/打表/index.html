打表（方法论，不是独立算法）

打表几乎不会单独出成「打表专题」，它是个解题工具，嵌在博弈论、数论、递推找规律里。
不要为打表单独开一堆题单去刷，而是养成习惯：遇到卡住的题，先写暴力打表观察。

先分清「打表」到底指哪种

类型 是什么 要不要练
打表找规律（核心） 本地暴力跑小数据 → 打印序列/矩阵 → 观察周期、二进制、递推 → 猜公式 → 证明/对拍 真正要练的
分段打表 范围太大（如 1e18 + 取模）跑不完存不下 → 暴力每 K 个取代表点嵌代码，再快速跳 数论技巧，进阶
真·离线打表 答案表直接嵌进代码硬输出 一般只在答案种类极少时 OJ 放行，不是出题人想考的
伪·打表（常混淆） 前缀和、线性筛这类「预处理数组」 这是标准空间换时间算法，不叫打表，别归错类

找规律的标准流程

  1. 暴力先保证正确 —— 暴力错了后面全白搭。
  2. 表要打得够大 —— 很多规律在小表下成立、扩大就崩（CF1906G 就是反例）。猜完必须对拍更大范围验证，不能打出就收。
  3. 观察维度别只看数值：最常藏规律的是
    • 二进制：末尾连续 0 / lowbit / 或、异或、与的结果
    • 奇偶分治
    • 周期长度（循环节）
    • 与 n 的关系、相邻差
  4. 落地常常还要优化：找到公式后往往要配 O(log)/O(1)，甚至大数（bitset），不是打印出来就行。
  5. 检验标准不是 AC，而是：能不能讲清为什么是这个规律？换参数还成立吗？

刷题路线（易 → 难）

  1. 洛谷 UVA1482 — Playing With Stones（入门）—— 取石子，SG(n)：偶数 =n/2，奇数 =SG(n/2)。「打表 → 猜 → 证」最标准的样板题。
    UVA1482
  2. 洛谷 P2148 [SDOI2009] E&D（中等）—— SG 经典题，每对石子是独立游戏。打表后规律藏在二进制里（(i-1)|(j-1) 的最低 0 位）。做完基本掌握「SG + 打表找规律」套路。
    P2148 E&D
  3. 洛谷 P2594 染色游戏（进阶）—— 二维翻硬币 SG 打表，出 lowbit / 2 的幂规律，还带大数（bitset）处理。
    P2594 染色游戏
  4. CF1906G — Grid Game 2（偏难，进阶练手）—— 专治「小表规律是假象」，反复 hack 自己的猜想。
    CF1906G

使用建议

  • 打表找规律跟着博弈论（SG 专题）一起学，别孤立地练。
  • 标准动作：做博弈题先暴力打 SG 表 → 找周期/二进制规律 → 再想证明。
  • 归档时这一篇挂在博弈/数论的方法论下更合适，别当独立算法收藏。
